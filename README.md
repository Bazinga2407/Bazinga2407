## 🚀 Featured projects

### [ComplaintOps](https://complaintops.onrender.com/): AI-assisted financial complaint operations
A deployed, human-in-the-loop platform that routes consumer complaints using a RAG agent with cited recommendations.
- Ingested **12,267** real CFPB complaints and embedded **11,967** narratives in PostgreSQL/pgvector
- Dual-collection retrieval over historical complaints and internal policy; reviewers approve, edit, or reject with a full audit trail
- Production hardening: OIDC auth, RBAC, PII redaction, CSRF protection, rate limiting, CI/CD, cost-capped embedding jobs, scheduled data refreshes

`React` `FastAPI` `PostgreSQL` `pgvector` `RAG` `Docker`

### [Network Phishing Detection](https://github.com/Bazinga2407/REPLACE-WITH-REPO-NAME): end-to-end MLOps pipeline
- Modular pipeline with automated data validation, transformation, and training, syncing artifacts to AWS S3
- MongoDB ingestion, FastAPI model serving, Dockerized with CI/CD deployment to AWS EC2

`Python` `MongoDB` `FastAPI` `Docker` `AWS S3` `AWS EC2`

### GPU-accelerated 3D co-localization pipeline (NYU research)
- Reproducible Nextflow + CuPy pipeline on NYU HPC measuring how biological markers co-locate in 3D tissue imaging
- Modular, resumable stages validated against the original method; output feeds the lab's interactive visualization tools

`Nextflow` `CuPy` `Python` `HPC` `Docker`
